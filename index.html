وثيقة متطلبات وتصميم نظام إدارة تكاليف صويلح (SRS)

دليل فني ومعماري شامل لمبرمجي ومطوري النظام، يوضح هياكل البيانات، منطق التجديد التلقائي، مصفوفة الصلاحيات، والربط السحابي المباشر عبر Firebase Realtime Database.

1

نظرة عامة على النظام (Overview)

نظام داخلي لإدارة ومتابعة التكاليف الثابتة والمصاريف الدورية لمؤسسة صويلح (إيجارات الفروع، سكن العمال، الرسوم الحكومية، التراخيص، والاشتراكات البرمجية) مع مؤقتات تنازلية حية لمنع الغرامات وتحديث تواريخ الاستحقاق تلقائياً فور السداد.

2

محرك التنبيهات والترميز اللوني

  • 🔴 أحمر (حرج / متأخر): متبقي ≤ 7 أيام أو متأخر.
  • 🟡 أصفر (تنبيه مسبق): متبقي من 8 إلى 30 يوماً.
  • 🟢 أخضر (آمن ومستقر): متبقي أكثر من 30 يوماً.
3

الصلاحيات وإدارة الأدوار (RBAC)

  • 👑 مدير النظام (Admin): إضافة، تعديل، حذف، وتأكيد السداد وتجديد الدورة.
  • 👁️ مستخدم المشاهدة (Viewer): استعراض لوحة التحكم والمؤقتات والتقارير دون إمكانية التعديل.
🔄

دورة إعادة تفعيل المؤقت بعد الدفع (Renewal Cycle Logic)

آلية الأتمتة المنطقية عند تأكيد سداد أي التزام مالي

1️⃣
الأرشفة والتوثيق

حفظ سجل تاريخي في أرشيف السدادات بالمبلغ وتاريخ الدفع والمسؤول.

2️⃣
احتساب التاريخ الجديد

إضافة (+1 شهر، +3 أشهر، +6 أشهر، +سنة) للتاريخ حسب دورية البند.

3️⃣
إعادة ضبط الحالة

إرجاع حالة الالتزام إلى "غير مدفوع" للدورة الجديدة المتولدة.

4️⃣
تشغيل المؤقت التنازلي

إعادة تشغيل العداد التنازلي فوراً وتحويل لونه للأخضر 🟢 تلقائياً في السحابة.

  }

{
  "items": [ /* قائمة التزامات صويلح والمؤقتات الدورية */ ],
  "archive": [ /* سجل السدادات التاريخية */ ],
  "lastUpdated": "2026-10-21T13:00:00Z"
}
🗄️

مخطط قاعدة البيانات العلائقية (Relational SQL Schema DDL)

أكواد SQL احتياطية لقواعد بيانات PostgreSQL أو MySQL لمن يرغب بتطبيق محلي

-- 1. جدول بنود التكاليف الثابتة
CREATE TABLE cost_items (
    id VARCHAR(50) PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    category VARCHAR(50) NOT NULL,        -- 'rentals', 'government', 'tech'
    subcategory VARCHAR(50) NOT NULL,
    amount DECIMAL(12, 2) NOT NULL,
    due_date DATE NOT NULL,
    recurrence VARCHAR(20) NOT NULL,      -- 'monthly', 'quarterly', 'semi_annual', 'annual'
    target_entity VARCHAR(255),           -- اسم الفرع أو الموظف
    notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. جدول أرشيف السدادات والتدقيق المالي
CREATE TABLE payment_archive (
    id VARCHAR(50) PRIMARY KEY,
    cost_item_id VARCHAR(50) REFERENCES cost_items(id),
    item_title VARCHAR(255) NOT NULL,
    amount_paid DECIMAL(12, 2) NOT NULL,
    cycle_due_date DATE NOT NULL,
    next_due_date DATE NOT NULL,
    paid_by VARCHAR(100) NOT NULL,
    ref_number VARCHAR(100),
    paid_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
