# رادار تكاليف صويلح | CostFlow Dashboard

نظام متكامل ومباشر لإدارة ومتابعة **التكاليف الثابتة والمصاريف الدورية** لمؤسسة صويلح (إيجارات الفروع، سكن العمال، الرسوم والتراخيص الحكومية، والاشتراكات التقنية ونقاط البيع). يتميز بمؤقتات تنازلية حية للتنبيه قبل مواعيد الاستحقاق، ودورة تجديد آلية فورية عند تأكيد السداد، مع مزامنة سحابية مباشرة عبر **Google Firebase Realtime Database**.

---

## 🚀 المميزات الرئيسية

1. **مزامنة سحابية لحظية (Live Firebase Realtime Database):**
   - متصل مباشرة بقاعدة البيانات: `https://asir-a738d-default-rtdb.asia-southeast1.firebasedatabase.app`
   - يدعم التزامن اللحظي (Server-Sent Events) لتحديث البيانات فوراً عبر كافة الأجهزة والمتصفحات.
   - يدعم التخزين المحلي الاحتياطي (Offline Cache) لضمان استمرار العمل عند انقطاع الاتصال.

2. **محرك التنبيهات والترميز اللوني الذكي:**
   - 🔴 **حرج / متأخر (&le; 7 أيام):** وميض أحمر مع مؤقت تنازلي بالثواني لتفادي الغرامات.
   - 🟡 **وشيك (8 - 30 يوماً):** تنبيه مسبق لترتيب السيولة المالية المطلوبة.
   - 🟢 **آمن ومستقر (> 30 يوماً):** حالة مستقرة للمصاريف طويلة المدى.

3. **دورة التجديد الآلي (Renewal Automation):**
   - عند الضغط على "سداد وتجديد"، يتم توثيق العملية وحفظها برقم مرجعي في أرشيف السدادات التاريخية.
   - يُعاد احتساب تاريخ الاستحقاق القادم تلقائياً حسب الدورية (شهري، ربع سنوي، نصف سنوي، سنوي) وتصفير المؤقت للأخضر.

4. **لوحة مؤشرات مالية ورسوم بيانية:**
   - حساب فوري لمتوسط التكاليف الشهرية وإجمالي المبالغ المستحقة حسب مستوى الأولوية.
   - رسم بياني دائري لتوزيع المصاريف حسب الأقسام (إيجارات، حكومية، تقنية).
   - رسم بياني للأعمدة للتدفقات النقدية والسيولة المطلوبة للأشهر القادمة.

5. **إدارة الصلاحيات (RBAC):**
   - 👑 **المدير المالي (Admin):** كامل الصلاحيات لإضافة، تعديل، حذف، وتأكيد السداد.
   - 👁️ **مشاهد فقط (Viewer):** استعراض المؤشرات والمؤقتات والتقارير دون إمكانية التعديل.

6. **تصدير التقارير (Excel CSV):**
   - تصدير كامل بنود التكاليف بترميز UTF-8 المتوافق بنسبة 100% مع برامج Microsoft Excel باللغة العربية.

7. **وثيقة المتطلبات القياسية (SRS View):**
   - تبويب متكامل مدمج يحتوي على مواصفات هندسة البرمجيات (IEEE 830)، هياكل البيانات، ومخططات قواعد البيانات العلائقية والسحابية.

## 🛠️ معلومات قاعدة بيانات Firebase

- **نوع قاعدة البيانات:** Firebase Realtime Database
- **المنطقة (Region):** `asia-southeast1` (سنغافورة)
- **عنوان الاتصال (URL):**
  ```text
  https://asir-a738d-default-rtdb.asia-southeast1.firebasedatabase.app
  ```
- **قواعد الأمان والصلاحيات (Rules):**
  ```json
  {
    "rules": {
      ".read": "now < 1795122000000",
      ".write": "now < 1795122000000"
    }
  }
  ```

## 🌐 خطوات الرفع على GitHub و GitHub Pages

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub.
2. ارفع ملفات المشروع (`index.html` و `README.md`) إلى المستودع.
3. لتشغيل الموقع كصفحة ويب مباشرة مجاناً:
   - اذهب إلى إعدادات المستودع **Settings**.
   - من القائمة الجانبية اختر **Pages**.
   - في قسم **Build and deployment**:
     - اختر الفرع: `main` (أو `master`).
     - اختر المجلد: `/ (root)`.
     - اضغط على **Save**.
4. خلال ثوانٍ سيظهر لك رابط الموقع الحي ليعمل مباشرة أونلاين على متصفحك أو هاتفك.
